# 🏥 Prior Authorization Journey – Healthcare Education Simulator

An interactive web-based healthcare education simulator that helps patients understand the **Prior Authorization (PA)** process through a realistic, story-driven experience.

## 📌 Overview

Prior Authorization can often feel confusing and stressful for patients. This simulator transforms the process into an engaging learning journey, allowing users to follow a patient from diagnosis to insurance approval while learning each step involved.

## ✨ Features

* 📖 Story-based learning experience
* 💬 Interactive doctor–patient conversations
* 📊 8-step progress tracker
* 📑 Realistic Prior Authorization workflow
* ❌ Insurance denial & appeal simulation
* ✅ Approval outcome with educational insights
* 📚 Key takeaways and industry facts
* 📱 Responsive and clean UI

## 🛤️ Journey Flow

1. Doctor Visit
2. PA Submitted
3. What is Prior Authorization?
4. Insurance Review
5. Denial
6. Appeal Filed
7. Approval
8. Final Takeaways

## 🩺 Learning Objectives

* Understand Prior Authorization
* Learn why insurance companies require PA
* Recognize common reasons for denial
* Understand how appeals work
* Learn best practices for patients
* Improve healthcare literacy
