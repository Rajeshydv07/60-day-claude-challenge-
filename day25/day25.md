# 🚀 AI Shark Tank Simulator

An interactive web application that simulates a **Shark Tank-style startup pitch** using AI-inspired evaluation. Users submit startup details and receive a professional investment analysis, startup score, valuation, funding recommendation, and final investment decision.

---

## 📌 Features

- 📝 Startup Pitch Submission Form
- 🤖 AI-Based Startup Evaluation
- 📊 Multi-Criteria Scorecard
- 💰 Funding Recommendation
- 💎 Startup Valuation Estimation
- 🤝 Investment Decision (Acquire / Invest / Pass)
- 📄 Download Pitch Report
- 🏆 Leaderboard
- 📱 Responsive User Interface
- 🎨 Modern Dashboard Design

## 🎯 How It Works

1. Enter startup details.
2. Fill in business information.
3. Start the AI Shark Tank simulation.
4. AI evaluates the startup across multiple business criteria.
5. Receive:
   - Market Score
   - Innovation Score
   - Business Score
   - Execution Score
   - Investment Score
6. Get:
   - Overall Score
   - Suggested Valuation
   - Recommended Funding
   - Final Investment Decision
