Agent roster & responsibilities

Planner
Reads the topic + audience and produces a structural outline: angle, sections, and the evidence each section needs. Runs once, before drafting begins.
Executor
Writes the first full draft from the Planner's outline. Runs once, seeding the loop.
Evaluator
Scores the current draft against a four-part rubric (clarity, depth, accuracy, engagement) and returns a strict JSON verdict every round.
Critic
Takes the Evaluator's verdict and the draft, and writes a prioritized, actionable critique — what's weakest and exactly what to fix.
Improver
Receives the prior draft, the evaluation, and the critique, and produces a revised full draft. This is the only agent allowed to rewrite the manuscript.
Memory Manager
Summarizes what changed this round and what pattern to carry forward, so later rounds don't re-litigate settled decisions.
Final Reviewer
Runs once a stop condition fires. Proofreads the winning draft, confirms it actually earns its score, and writes the closing QA note.

How the stop-check governs information flow: after every Evaluator→Critic→Improver→Memory pass, the orchestrator checks three conditions in order — (1) plateau: composite score gained less than 3 points for two consecutive rounds; (2) threshold: composite score has crossed the target set in the brief; (3) hard cap: a safety-only ceiling on rounds. Whichever fires first ends the loop and the exact reason is logged and shown below. Only then does control branch to the Final Reviewer — evaluation state never reaches the reviewer mid-loop.

Extension ideas & further prompts

  • Add a Safety Monitor agent — run it in parallel with the Evaluator to flag unverifiable claims or biased framing before the Critic sees the draft.
  • Parallel drafts: run 2–3 Executor drafts from the same outline and have the Evaluator pick a winner before entering the improvement loop.
  • Source grounding: give the Planner a web-search tool so the outline cites real, checkable sources instead of Claude's own knowledge.
  • Human-in-the-loop gate: pause after the Critic step and let a person approve or edit the critique before the Improver runs.
  • Multi-format fan-out: once the article passes, add a "Repurposer" agent that turns the final draft into a thread, a newsletter blurb, and a slide outline.
  • Try asking: "Add a Safety Monitor that runs a fact-check pass on every third round" or "Make the stopping condition a weighted rubric where accuracy counts double."
