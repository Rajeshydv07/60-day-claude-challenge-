# 💰 Personal Financial Command Center

A modern, interactive personal finance dashboard built using **HTML, CSS, and JavaScript**. This project helps freelancers and individuals manage irregular income, monitor expenses, build an emergency fund, plan investments, and simulate financial scenarios—all within a beautiful responsive interface.

---

## 📌 Features

### 📊 Financial Overview
- Financial Health Score
- Average Monthly Income
- Average Monthly Expenses
- Emergency Fund Tracking
- Monthly SIP Overview
- AI-powered financial recommendations

### 💵 Income Management
- Add and remove income records
- Monthly income trend visualization
- Income variability analysis
- Client/source tracking

### 💳 Expense Tracker
- Categorize expenses
- Fixed vs Variable expense tracking
- Interactive expense distribution chart
- Expense history management

### 🛟 Emergency Fund Planner
- Calculate target emergency fund
- Track current progress
- Estimate months covered
- Goal completion timeline

### 📈 Investment Planner
- SIP Calculator
- Future investment projection
- Compound interest simulation
- Beginner investment guidance

### 📅 Cash Flow Calendar
- Upcoming income tracking
- Fixed expense reminders
- Cash flow visualization

### 🔬 What-If Simulation Lab
Simulate different financial situations:
- Low-income month
- Annual SIP increase
- Large client payment scenario

### 📚 Financial Learning Center
- Personal finance checklist
- Smart financial tips
- AI prompt suggestions
- Financial literacy resources

### 🎨 UI Features
- Responsive Design
- Dark/Light Theme
- Animated dashboard
- Print Report option
- Local Storage support
- Mobile Friendly
