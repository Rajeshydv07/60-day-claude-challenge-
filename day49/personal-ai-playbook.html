What this tool is

This is your personal library of reusable AI prompt systems — built for final-year CS/IT students prepping for placements. Instead of writing a new prompt from scratch every time, you save workflows (editable prompt templates with fill-in-the-blank variables), assemble new prompts piece-by-piece in the Prompt Builder, and turn any prompt into a self-correcting Loop that iterates until it meets a goal you define.

  • ▤ Workflows = your saved, reusable prompts
  • ✎ Prompt Builder = assemble a new prompt from labeled parts
  • ↻ Loop Builder = make a prompt repeat & self-improve until done

What is the AI Playbook?

A quick tour of every section

This app is a personal system for reusing AI prompts instead of rewriting them every time — built around what you told the interview: final-year student, heavy on coding/DSA debugging, and wanting fast, tailored job applications.

▤ My Workflows

Your saved prompt templates. Each one has fill-in variables (e.g. the language, the error, the job title) so you customize once and copy the finished prompt. Search, filter by category, favorite the ones you use daily, duplicate to make variants.

✎ Prompt Builder

Build a brand-new prompt piece by piece — role, objective, context, constraints, reasoning strategy, output format, tone, examples, quality checks. Add only the pieces you need; each one is explained inline. A live preview updates as you go. Save the result as a new workflow.

↻ Loop Builder

Takes any normal prompt and wraps it in an autonomous loop: the AI does the task, checks its own work against criteria you set, improves it, and repeats until a stop condition is met (or a safety rule kicks in). Useful for things like "keep refining this resume bullet until it's under 20 words and has a metric."

Library categories

Coding & Debugging, Resume & Applications, Interview Prep, and Learning & Summaries — picked because these matched what you said you use AI for most, so nothing irrelevant is shown.
