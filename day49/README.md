# 🤖 Personal AI Playbook

A modern AI-powered prompt management platform that helps developers, students, and professionals organize, build, and reuse high-quality AI workflows.

Designed with a clean dashboard, reusable prompt templates, prompt builder, and autonomous loop builder, the application makes prompt engineering simple, structured, and efficient.

---

## ✨ Features

### 📊 Dashboard
- Overview of saved workflows
- Favorite prompts
- Category-wise organization
- Prompt statistics

### 📂 Workflow Library
- Save reusable AI prompts
- Edit and duplicate workflows
- Search and filter prompts
- Favorite important workflows
- Categorize workflows

### ✍️ Prompt Builder
Build prompts using reusable components such as:

- Role
- Objective
- Context
- Constraints
- Reasoning Strategy
- Output Format
- Tone
- Examples
- Quality Checks

Live preview updates while building prompts.

### 🔄 Loop Builder
Convert normal prompts into self-improving AI workflows.

Supports:

- Goal definition
- Evaluation criteria
- Improvement strategy
- Stop conditions
- Safety rules

Perfect for iterative AI tasks.

### 🎯 Prompt Categories

- 💻 Coding & Debugging
- 📄 Resume & Applications
- 🎤 Interview Preparation
- 📚 Learning & Summaries
- 📝 Custom Workflows

### 🌙 User Experience

- Dark & Light Theme
- Responsive UI
- Command Palette
- Global Search
- Local Storage Persistence
- Import / Export Workflows
- Interactive Modals
- Toast Notifications
