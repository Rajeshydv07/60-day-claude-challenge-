# 🧭 Task Compass – Organizational Thinking Dashboard

An interactive web-based simulation that teaches how work flows through a modern tech company by helping users understand ownership, task routing, delegation, collaboration, and cross-functional decision-making.

---

## 📌 Overview

Task Compass is an educational management simulation that helps users learn how real organizations assign work, collaborate across departments, and make ownership decisions.

Instead of testing technical skills, the application focuses on organizational thinking through realistic workplace scenarios. Users progress through three interactive stages and receive a personalized Organizational Thinking Dashboard at the end of the simulation.

## 🚀 Simulation Flow

### Stage 1 — Who Owns This?

Determine the primary owner for incoming organizational tasks.

Example scenarios:

- QA finds a released feature doesn't match the original design.
- Engineering team keeps missing sprint deadlines.
- Marketing requests a landing page redesign.

---

### Stage 2 — Task Routing

Build the correct workflow by arranging departments in the order work typically flows.

Example scenarios:

- Payment checkout failure
- Enterprise analytics dashboard request
- Product feature implementation

---

### Stage 3 — Collaboration Challenge

Select the appropriate teams that should collaborate on complex organizational situations.

Example scenarios:

- Sales increase dramatically overnight.
- Customer complaints about usability.
- Cross-functional product investigation.
