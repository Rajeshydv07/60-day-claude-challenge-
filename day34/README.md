# 🕵️ Marketing Detective

> **Case Files of Campaigns Gone Wrong**  
An interactive marketing investigation game where you analyze real-world campaign failures, uncover hidden problems, and learn strategic marketing lessons.

![Marketing Detective Banner](assets/banner.png)

---

## 📌 Overview

Marketing Detective transforms marketing case studies into an engaging detective experience.

Instead of reading theory, players investigate campaign evidence, analyze customer feedback, examine performance metrics, and identify the real reason behind a failed marketing campaign.

Each completed investigation generates a professional learning report with actionable business insights.

---

## ✨ Features

- 🕵️ Interactive detective-style gameplay
- 📂 Random marketing case generation
- 📊 Real-world marketing metrics
- 📌 Evidence board with draggable cards
- 💬 Customer review analysis
- 📈 Campaign performance evaluation
- 🎯 Multiple-choice investigation system
- ✅ Instant feedback with explanations
- 📑 Marketing learning report
- 🎉 Case Closed animation
- 📱 Fully responsive design
- 🌙 Modern dark detective UI

---

## 🎮 Gameplay Flow

1. Accept a new marketing case.
2. Read the campaign brief.
3. Investigate the evidence board.
4. Examine customer comments.
5. Analyze campaign metrics.
6. Study marketing channels.
7. Identify the primary marketing mistake.
8. Close the case.
9. Receive a detailed learning report.
