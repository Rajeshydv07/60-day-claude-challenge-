# 🚀 Day 33 of the ABTalks x Claude 60 Days Challenge

## 📰 Media Integrity Analyzer

Today I built an interactive **Media Integrity Analyzer**, a web application designed to improve digital media literacy by helping users recognize misleading headlines, emotional manipulation, and audience-targeting techniques commonly used across online content.

In a world where misinformation spreads faster than facts, learning **how to analyze content critically** is becoming an essential skill.

---

## ✨ Features

- 🎯 Interactive media literacy learning experience
- 📰 Headline Accuracy Analysis
- 🔍 Source Reliability Evaluation
- ❤️ Emotional Manipulation Detection
- 👥 Audience Targeting Identification
- 📊 Media Integrity Dashboard
- 🎨 Multiple UI Themes
- ⚡ Smooth animations and responsive design
- 💻 Built using pure HTML, CSS & JavaScript

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive UI Design
- Interactive Dashboard

---

## 💡 What I Learned

Building this project helped me understand:

- How misleading headlines influence user behavior
- Emotional triggers used to increase engagement
- Importance of evaluating information before sharing
- Designing educational user experiences
- Creating interactive dashboards with vanilla JavaScript
- Structuring multi-step web applications

---

## 🎯 Key Takeaways

✔ Read beyond the headline.

✔ Verify the original source.

✔ Recognize emotional manipulation.

✔ Think critically before reacting or sharing.

✔ Digital literacy is an essential skill in the AI era.
