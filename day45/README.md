# 🧠 Decision Strategist

An AI-inspired interactive decision-making web application that helps users analyze difficult choices using structured reasoning, cognitive bias detection, decision matrices, and actionable recommendations.

---

## 🚀 Overview

**Decision Strategist** transforms complex decisions into a clear, data-driven process.

Instead of relying purely on emotions, users answer four guided questions. The application then generates a personalized decision report including:

* Decision breakdown
* Option analysis
* Cognitive bias detection
* Decision matrix
* Premortem analysis
* 7-Day action plan
* Final recommendation
* Shareable summary cards

Everything runs **locally in the browser** with **no backend or API required**.

---

## ✨ Features

### 🎯 Interactive Decision Interview

* 4 guided questions
* Clean step-by-step interface
* Progress tracking
* Input validation

### 📊 Decision Analysis

* Identifies the real decision
* Extracts available options
* Evaluates strengths and weaknesses
* Highlights hidden opportunities

### 🧠 Cognitive Bias Detection

Automatically detects common thinking biases such as:

* Loss Aversion
* Confirmation Bias
* Status Quo Bias
* Sunk Cost Fallacy
* Social Proof / FOMO

---

### 📈 Decision Matrix

Evaluates every option across multiple dimensions:

* Career & Life Upside
* Financial Safety
* Growth & Learning
* Stress Level
* Reversibility
* Long-Term Alignment
* Regret Risk

Animated score bars make comparisons easy.

---

### ⚠️ Premortem Analysis

For each option, the report predicts:

* Why it could fail
* Early warning signs
* Preventive actions

Helping users avoid future mistakes before they happen.

---

### 📅 7-Day Action Plan

Provides a practical roadmap including:

* Research tasks
* Small experiments
* Difficult conversations
* Final decision checkpoint

---

### 🏆 Final Verdict

Generates:

* Best recommended option
* Reasoning behind the recommendation
* What could change the outcome
* Honest "Hard Truth" insight

---

### 📢 Shareable Cards

Creates concise summaries for:

* Decision Matrix
* Final Verdict
* LinkedIn-style reflection

## ⚙️ How It Works

1. User answers four guided questions.
2. JavaScript analyzes the responses.
3. Decision options are extracted.
4. Cognitive biases are detected.
5. A multi-factor decision matrix is generated.
6. Premortem scenarios are created.
7. A personalized recommendation is displayed.

All processing happens entirely inside the browser.
