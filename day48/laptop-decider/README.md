# 💻 Work Laptop Decider (Under ₹60,000)

An interactive web application that helps working professionals compare and rank the best laptops under **₹60,000** based on their personal priorities.

Instead of relying on fixed recommendations, users can adjust the importance of different factors like **Performance**, **Battery Life**, **Display**, and **Warranty**, and the rankings update instantly.

---

## ✨ Features

- 🎯 Interactive weight sliders for decision making
- 📊 Live ranking based on custom priorities
- 💰 Compare laptops under ₹60,000
- 📋 Detailed comparison table
- 🔍 Transparent research methodology
- 📚 Complete list of data sources
- 📱 Fully responsive design
- ⚡ Instant score recalculation
- 🏷️ Estimated values clearly marked

## 📈 Evaluation Criteria

The ranking is calculated using four important parameters:

- 🚀 Performance
- 🔋 Battery Life
- 🖥️ Display Quality
- 🛡️ Warranty & Support

Users can assign custom weights (0–100) to each criterion.

## ⚙️ How It Works

1. Open the webpage.
2. Adjust the sliders based on what matters most to you.
3. Rankings update automatically.
4. Compare detailed specifications.
5. Review research notes and cited sources before making a purchase.

---

## 📊 Decision Model

Each laptop receives normalized scores for:

- CPU Performance
- Battery Runtime
- Display Quality
- Warranty Coverage

The final score is calculated using weighted averages based on user preferences.
