# 🧠 Day 36 – Cognitive Pattern Explorer

> **Phase:** Human-Centered AI & Interactive Psychology Experience

## 📌 Overview

Day 36 focuses on building an interactive **Cognitive Pattern Explorer**, a web application that helps users discover their natural thinking and decision-making patterns through engaging scenarios, priority ranking, and reflective exercises. Rather than providing a psychological diagnosis, the application encourages self-awareness by analyzing user choices and generating a personalized thinking snapshot.

---

## 🎯 Objective

The goal of this project is to create a responsive and interactive web application that:

- Explores individual thinking styles
- Uses scenario-based decision questions
- Allows users to rank personal priorities
- Maps natural decision-making sequences
- Generates personalized cognitive reflections
- Supports both Calm Mode and Stress Mode experiences
