Slide vs lecture
Random Forest = bagging of decision trees
Each tree trains on a random subset of data + features. Reduces overfitting.
OOB Error
Out-of-bag error used as internal validation. No need for separate validation set.
Feature importance via Gini impurity
RF ranks features by how much they reduce impurity across all trees.
Bagging vs Boosting
Bagging: parallel, reduces variance. Boosting: sequential, reduces bias. Prof said boosting often outperforms but is slower.
