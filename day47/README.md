# 🧠 Content Intelligence Studio

> AI-powered X (Twitter) Post Critique & Optimization Platform

Content Intelligence Studio is an intelligent web application that analyzes X (Twitter) posts using a panel of specialized AI reviewers. Instead of receiving generic feedback, users get detailed insights from multiple perspectives including hook quality, engagement psychology, platform strategy, copywriting, and visual analysis.

---

## ✨ Features

- 📝 Analyze X (Twitter) post content
- 🖼️ Upload screenshots for visual review
- 🤖 Multi-Agent AI Review System
  - Hook Analyst
  - Engagement Psychologist
  - X Platform Strategist
  - Copy Editor
  - Visual Analyst (for images)
- 📊 Overall Quality Score (0–100)
- 📈 Category-wise Performance Breakdown
- 💪 Strengths & Weakness Analysis
- 🚀 Missed Opportunities Detection
- ✍️ AI-Generated Tweet Rewrites
- 🎯 Alternative Hook Suggestions
- ✅ Publishing Checklist
- 📉 Performance Prediction
- 📄 Executive Content Health Report
- 📋 One-click Copy for Improved Tweets

## 🚀 How It Works

1. Paste your X (Twitter) post.
2. Optionally upload a screenshot.
3. Click **Run Full Review**.
4. AI reviewers analyze your content.
5. Receive:
   - Overall score
   - Category analysis
   - Rewrite suggestions
   - Better hooks
   - Engagement prediction
   - Full optimization report
