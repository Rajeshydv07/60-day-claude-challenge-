# 🏥 Hospital Admission Readiness Simulator

An interactive web-based simulator that evaluates patient admission readiness across critical healthcare workflows. The application provides a dynamic readiness score, tracks workflow completion, and simulates real-world hospital admission processes to improve operational decision-making.

---

## 📌 Project Overview

The **Hospital Admission Readiness Simulator** is designed to replicate the patient admission workflow used in healthcare organizations. It helps users understand how multiple administrative and clinical processes contribute to admission readiness before a patient can be admitted.

The simulator evaluates several workflow components, provides a readiness score, identifies missing requirements, and generates a final admission decision.

## 🚀 How to Run

1. Clone this repository.

```bash
git clone https://github.com/your-username/hospital-admission-readiness-simulator.git
```

2. Open the project folder.

3. Launch the `hospital_admission_simulator.html` file in your browser.

No installation or backend setup is required.

---

## ⚙ Workflow

1. Select Provider & Physician
2. Choose Diagnosis
3. Select Admission Type
4. Select Prior Authorization Status
5. Analyze Admission Readiness
6. Complete Pending Workflow Actions
7. Recalculate Readiness Score
8. Review Final Admission Decision

## 📊 Readiness Dimensions
