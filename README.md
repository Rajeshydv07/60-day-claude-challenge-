## 🔄 Daily Update Workflow

To keep this repository up-to-date and maintain this showcase, we will follow a simple daily workflow.

### 📥 What You Provide Me Each Day
To document and push your daily progress, please provide me with:
1. 📸 **A Screenshot of your Claude Work:** Save your daily screenshot as an image (PNG or JPG) or drop it in a folder (e.g., `screenshots/`), or paste the image file path directly in our chat.
2. 📝 **A Brief Description:** Tell me what we worked on or solved that day (e.g., *"Today we implemented an XGBoost model and compared it to Random Forest"*).
3. 💻 **Code/Notebook Files (Optional):** Any notebook, script, or project file you want to commit to the repository under the daily folder (e.g., `day01/`, `day02/`).

### ⚙️ My Role
Once you provide the above:
1. I will organize your files into a dedicated daily folder (e.g., `day19/`).
2. I will save and reference your screenshot in the `screenshots/` directory.
3. I will update the **Daily Tracker** table in this `README.md` with the date, focus, and key takeaways.
4. I will stage all changes, write a professional commit message, and commit/push the files to your GitHub repository.
