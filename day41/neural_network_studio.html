MODULE 1 / FOUNDATIONS

The Artificial Neuron

What a perceptron actually computes, and why "weights" and "bias" are the only two things it ever learns.

Core idea

A biological neuron receives electrical signals from other neurons, and only "fires" if the combined signal is strong enough. An artificial neuron (perceptron) is a deliberately simplified version of that idea: it takes several numeric inputs, multiplies each by a weight, adds a bias, and passes the total through an activation function to decide its output.

z = (x₁·w₁ + x₂·w₂ + ... + xₙ·wₙ) + b   →   output = activation(z)
Diagram — a single perceptron
Analogy Think of a bouncer at a club deciding whether to let you in. Each factor — your name on the guest list, how dressed up you are, how full the club is — is an input. The bouncer weighs some factors more than others (guest list matters a lot, outfit a little) — those are the weights. Their personal "leniency" that night is the bias. If the combined score clears their threshold, you get in — that's the activation.
Worked example

Inputs x₁=1, x₂=0.5, weights w₁=0.8, w₂=-0.3, bias b=0.1. Then z = (1·0.8)+(0.5·-0.3)+0.1 = 0.65. If we use a step activation (fire if z>0), this neuron fires with output 1.

Exercise
Hand-compute

A neuron has inputs x₁=2, x₂=-1, weights w₁=0.5, w₂=1.2, and bias b=-0.4. Using a step activation (fire if z>0), does it fire?

z = (2×0.5)+(-1×1.2)+(-0.4) = 1 - 1.2 - 0.4 = -0.6. Since z ≤ 0, the neuron does not fire. Output = 0.
Common misconceptions
"More weights always means smarter"A neuron with more inputs isn't inherently smarter — it just has more numbers to combine. Intelligence comes from correctly *learned* weight values across many neurons, not raw parameter count alone.
"Bias is a bug workaround"The bias isn't a hack — it lets the neuron shift its decision boundary away from the origin, which is essential for fitting real data that isn't centered at zero.
Key takeaways
  • A neuron = weighted sum of inputs + bias, passed through an activation function
  • Weights control *how much* each input matters; bias shifts the decision threshold
  • Training a network essentially means searching for good weight and bias values

MODULE 2 / GOING NON-LINEAR

Activation Functions

Why a network of only weighted sums can never learn anything interesting — and the functions that fix it.

Core idea

Stacking weighted sums without an activation function is pointless: a sum of sums is still just a bigger sum. Mathematically, chaining linear functions collapses back into one linear function, no matter how many layers you add. Activation functions inject non-linearity, which is what lets networks approximate curved, complex decision boundaries instead of only straight lines.

Analogy A purely linear neuron is like a dimmer switch that can only ever be "proportionally on" — brightness always scales exactly with the knob. A non-linear activation is like adding a smart bulb with its own logic: dim slowly at first, then rapidly brighten, then plateau at max. That extra shaping is what lets a lamp — or a network — represent complicated behaviour instead of one straight line.

Exercise
Choose the activation

You're building the output layer for a model that classifies an image into exactly one of 10 digit classes (0-9). Which activation belongs on that final layer, and why?

Softmax. It turns the 10 raw output scores into a probability distribution that sums to 1, so you can directly read off "there's an 87% chance this is a 7."
Common misconceptions
"ReLU is always the best choice"ReLU is a strong default for hidden layers, but the output layer's activation is dictated by the task (sigmoid for binary, softmax for multi-class, linear/none for regression) — not by what worked in the hidden layers.
"Activation functions are just for squashing numbers"Squashing the range is a side-effect, not the point. The real job is introducing non-linearity so the network can model curved relationships.
Key takeaways
  • Without non-linear activations, any deep network mathematically collapses into one linear function
  • ReLU is the default for hidden layers; sigmoid/softmax are typically reserved for output layers
  • Every activation has failure modes — vanishing gradients (sigmoid/tanh) or dead neurons (ReLU)

MODULE 3 / PUTTING IT TOGETHER

Layers & Forward Propagation

How single neurons combine into layers, and how a signal actually flows from input to prediction.

Core idea

A single neuron can only draw one straight decision line. Stack many neurons side by side into a layer, and stack layers one after another, and the network can bend and combine many lines into complex shapes. Forward propagation is simply the process of pushing input values through every layer, left to right, until you reach the final prediction.

Diagram — a 3-layer network
Analogy Think of an assembly line reviewing a loan application. The first station (input layer) reads raw facts: income, age, credit history. The next station (hidden layer) doesn't see the raw facts directly — it only sees combined signals like "financial stability score" built from the first station's outputs. The final station (output layer) takes those refined scores and makes one decision: approve or deny. Each station only passes forward, never backward — that's forward propagation.
Worked example — forward pass by hand

2 inputs → 2 hidden neurons (ReLU) → 1 output neuron (sigmoid).

Inputs: x₁=1, x₂=2
Hidden neuron A: z=(1×0.5)+(2×-0.2)+0.1=0.2 → ReLU(0.2)=0.2
Hidden neuron B: z=(1×0.3)+(2×0.4)+(-0.1)=1.0 → ReLU(1.0)=1.0
Output: z=(0.2×0.6)+(1.0×0.9)+0.05=1.07 → sigmoid(1.07)≈0.744

The network's final prediction for this input pair is ≈0.744 — read as "74.4% confidence of the positive class."

Exercise
Predict the shape

A network has 4 input features, two hidden layers of 8 and 5 neurons, and predicts one of 3 categories. How many neurons are in the output layer, and what activation would you likely use there?

3 output neurons (one score per category), with softmax activation so the three scores form a probability distribution over the classes.
Common misconceptions
"More hidden layers always means better accuracy"Deeper networks can model more complex functions, but they're also harder to train and more prone to overfitting on small datasets. Depth is a trade-off, not a free upgrade.
"Hidden neurons represent specific human-readable concepts"Sometimes hidden units do end up loosely tied to interpretable features, but usually they encode messy, distributed combinations of the input that don't map to any single human concept.
Key takeaways
  • Layers of neurons let a network combine many decision boundaries into complex shapes
  • Forward propagation = pushing values left-to-right through weights, biases, and activations
  • Output layer size and activation are dictated by the task, not by preference

MODULE 4 / MASTERY

Backpropagation & Learning

How a network figures out which weights to blame for a wrong answer, and nudges them in the right direction.

Core idea

After a forward pass produces a prediction, we compare it to the true answer using a loss function (a number that says "how wrong were you"). Backpropagation works backward through the network using the chain rule from calculus to compute exactly how much each individual weight contributed to that error. Gradient descent then nudges every weight slightly in the direction that reduces the loss.

Loss (example, squared error): L = (prediction − actual)²
Weight update: w_new = w_old − (learning_rate × ∂L/∂w)
Analogy Imagine a group project that got a bad grade. Backpropagation is like the professor going backward through the submission chain — "the final report was weak because slide 5 was wrong, which was wrong because the data-analysis teammate made an error, which happened because the raw data collector mislabeled a column." Each person gets precisely the amount of "blame" that traces back to their contribution. Gradient descent is then everyone slightly adjusting their approach next time, in proportion to how much blame they got — not overreacting, just a small correction (the learning rate controls how big that correction is).

Exercise
Diagnose the training run

You train a network and the loss oscillates wildly instead of smoothly decreasing. Which hyperparameter is the most likely culprit, and how would you adjust it?

The learning rate is almost certainly too high, causing the weight updates to overshoot the minimum each step. Lowering the learning rate usually smooths this out.
Common misconceptions
"Backpropagation is a separate learning algorithm from gradient descent"Backprop is just an efficient way to *compute* the gradients; gradient descent is the algorithm that *uses* those gradients to update weights. They work together, not as alternatives.
"A lower loss on training data always means a better model"Push training loss low enough and the network starts memorizing noise instead of learning general patterns — that's overfitting, and it hurts real-world performance.
Key takeaways
  • Loss quantifies how wrong a prediction is; gradients say how to reduce it
  • Backpropagation efficiently computes gradients for every weight using the chain rule
  • Learning rate controls step size — too high overshoots, too low trains painfully slowly

Summary notes
  • A neuron combines inputs via weights + bias, then applies an activation function
  • Non-linear activations are what let stacked layers model complex, curved relationships
  • Forward propagation pushes data left to right; backpropagation pushes error right to left
  • Gradient descent nudges weights toward lower loss, one small learning-rate-sized step at a time
  • Layer sizes and output activations are chosen based on the task, not preference
