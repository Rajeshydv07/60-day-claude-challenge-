# 📊 Customer Intelligence Platform

> An end-to-end Data Science project that transforms raw customer data into actionable business insights using Machine Learning, Predictive Analytics, and Interactive Dashboards.

## 🚀 Overview

The **Customer Intelligence Platform** is a production-ready analytics solution developed as the final capstone project of the **60 Days Data Science Challenge**. It enables businesses to understand customer behavior, predict future trends, identify valuable customer segments, detect anomalies, monitor KPIs, and make data-driven decisions through an interactive dashboard.

---

## ✨ Features

- 📊 Interactive Analytics Dashboard
- 👥 Customer Segmentation (K-Means)
- 💰 Customer Lifetime Value (CLV) Analysis

- 🔮 Sales Prediction
- ⚠️ Anomaly Detection
- 📉 Customer Churn Analysis

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Rajeshydv07/customer-intelligence-platform.git
```

Go to the project folder

```bash
cd customer-intelligence-platform
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
