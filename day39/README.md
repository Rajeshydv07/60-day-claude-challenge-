# 📄 PDF Splitter & Merger

A modern, responsive, and privacy-focused PDF Splitter & Merger built using **HTML, CSS, and JavaScript**. This application performs all PDF processing directly in the browser, ensuring your files never leave your device.

---

## ✨ Features

### 📑 PDF Splitter
- Upload a single PDF
- Live page preview with thumbnails
- Split by custom page ranges
- Split every N pages
- Split using manual cut marks
- Extract selected pages
- Download individual PDF files

### 📚 PDF Merger
- Upload multiple PDF files
- Drag & drop to reorder documents
- Merge PDFs into a single file
- Download merged PDF instantly

### 🎨 User Interface
- Responsive design
- Dark Mode support
- Drag & Drop upload
- Keyboard accessibility
- Progress indicators
- Toast notifications
- Clean modern UI
